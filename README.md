# Only-Focus-2

**An intelligent study planner and personal productivity system.**

Only-Focus-2 is a local-first study and productivity application designed to help students plan their work, maintain focus, track academic performance, and build consistent study habits. It combines task management, focus sessions, exam preparation, and an immersive monthly progress dashboard into one application.

### Core Features
- **Smart Study Planner:** Organize subjects, topics, tasks, deadlines, and upcoming examinations.
- **Focus Timer:** Track focused study sessions and record time spent on individual subjects.
- **Monthly Progress Overview:** An interactive calendar heat-map that preserves day-to-day progress, study hours, task completion, and productivity trends.
- **Daily Study Journal:** Review completed tasks, performance, energy levels, and reflections for any date.
- **Academic Analytics:** Compare planned versus actual study time, monitor past-paper scores, and identify weak topics.
- **AI Study Coach (Planned):** Use AI to analyze study history, identify learning gaps, and generate personalized, evidence-based study recommendations.
- **Data Persistence:** Store progress locally and support data export so users retain control over their records.

### Technology Stack
Python, SQLite, HTML, CSS, JavaScript, and AI/LLM integration.

### Project Philosophy
Build a reliable productivity system first, then integrate AI where it provides measurable value. The project emphasizes privacy, evidence-based recommendations, sustainable productivity, and maintainable software engineering.
